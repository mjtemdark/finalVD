# Dashboard-Turismo Receptivo en el Perú


**Dataset:** Turismo Receptivo en el Perú, publicado por el Ministerio de Comercio Exterior y Turismo (MINCETUR).

**Fuente:** [Plataforma Nacional de Datos Abiertos](https://www.datosabiertos.gob.pe/dataset/turismo-receptivo-en-el-per%C3%BA-ministerio-de-comercio-exterior-y-turismo-mincetur)

# Cómo ejecutar el proyecto

El proyecto utiliza **Streamlit** para la interfaz y **uv** para gestionar las dependencias.

## Requisitos

- Python
- [uv](https://docs.astral.sh/uv/)

## Instalación y ejecución

1. Abrir una terminal en la carpeta raíz del proyecto.
2. Instalar las dependencias:

   ```bash
   uv sync
   ```

3. Ejecutar la aplicación:

   ```bash
   uv run streamlit run home.py
   ```

4. Abrir en el navegador la dirección que muestra la terminal, normalmente:

   `http://localhost:8501`
